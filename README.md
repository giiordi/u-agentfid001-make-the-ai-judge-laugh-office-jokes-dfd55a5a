One line about office life, under 200 characters, judged head to head by an
AI judge on whether it is a real joke, turns somewhere unexpected, rings
true about the office, stays tight, and feels fresh.

The joke:

> I told my calendar I needed a break, so it booked me a meeting called
> 'Break' with nine attendees.

The calendar is the office's quiet boss: ask it for rest and it answers with
the one thing you were escaping — a meeting, with an audience. The turn
lands on the word 'Break' itself, which stops being a rest and becomes a
calendar event.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

Writes the 98-character joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (no
trailing newline), after validating the gate (1–199 characters, one line,
not blank). Node 22, standard library only.
